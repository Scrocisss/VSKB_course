**Сценарий.** Хостинг-провайдер «ОблакоСервис», 21 марта 2026, 23:40. После инцидента на `web-prod-3` проверяют, не завёл ли атакующий привилегированную учётную запись. Аналитик L1 снял `/etc/passwd`, `/etc/shadow`, группу `sudo` и `sudoers.d`.

**Исходные данные.** Файл `users-discovery.txt`. Фрагмент `/etc/passwd`:

```
root:x:0:0:root:/root:/bin/bash
www-data:x:33:33:www-data:/var/www:/usr/sbin/nologin
sshd:x:108:65534::/run/sshd:/usr/sbin/nologin
sysd:x:0:0::/root:/bin/bash
ubuntu:x:1000:1000:Ubuntu:/home/ubuntu:/bin/bash
```

**Задача.** По контрольному списку найти привилегированную учётную запись, заведённую атакующим, и снять её атрибуты.

**Решение по шагам.**

**Шаг 1 — проверить учётки с `UID 0`.** Третье поле в `/etc/passwd` — это UID. Легитимно `UID 0` только у `root`. Здесь `UID 0` ещё и у `sysd` — это вторая root-учётка, бэкдор.

**Контрольный вопрос 1.1.** Имя учётной записи с `UID 0`, кроме `root`? **Ответ:** `sysd`

**Шаг 2 — снять её атрибуты.** У `sysd` UID `0`, GID `0`, домашний каталог `/root`, оболочка `/bin/bash` (полноценный вход), а в `/etc/shadow` — настоящий хэш пароля, а не `!`, то есть в неё можно войти.

**Контрольный вопрос 1.2.** Какой UID у `sysd`? **Ответ:** `0`

**Контрольный вопрос 1.3.** Какая командная оболочка указана для `sysd`? **Ответ:** `/bin/bash`

**Шаг 3 — посчитать учётки с `UID 0`.** Их должно быть ровно одна (`root`).

**Контрольный вопрос 1.4.** Сколько всего учётных записей с `UID 0` в `/etc/passwd`? **Ответ:** `2`

**Вердикт.** True Positive: заведён root-бэкдор `sysd` (`UID 0`, оболочка `/bin/bash`, задан пароль). Снять атрибуты, эскалировать.

**Готовый результат.** В тикет: учётка `sysd`, `UID 0`, `GID 0`, shell `/bin/bash`, задан пароль — root-бэкдор.

**Ключевые уроки.**
- `UID 0` = права root; вторая учётка с `UID 0`, кроме `root`, — root-бэкдор.
- Служебные учётки в норме: оболочка `/usr/sbin/nologin`, пароль заблокирован (`!`/`*` в shadow).
- `NOPASSWD` в `/etc/sudoers.d/*` — повышение до root без пароля; членство в группе `sudo`/`wheel` — право повышаться.
- Контрольный список привилегий: учётки `UID 0`, записи `NOPASSWD`, члены `sudo`/`wheel`.
