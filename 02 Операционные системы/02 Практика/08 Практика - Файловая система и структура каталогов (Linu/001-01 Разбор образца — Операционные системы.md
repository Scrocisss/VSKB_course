**Покрывает листья** (ветка «Операционные системы / Основы Linux / Файловая система и структура каталогов»):
- Иерархия FHS и назначение ключевых каталогов
- Связь объектов файловой системы с правами и аудитом
- Mount points и виртуальные ФС (proc, sys, tmpfs)

**Сценарий.** Хостинг-провайдер «ОблакоСервис», 21 марта 2026, 03:10. На веб-сервере `web-prod-3` EDR отметил запуск файла из временного каталога. Аналитик L1 снял список монтирований (`mount`).

**Исходные данные.** Файл `mount-discovery.txt`. Часть строк:

```
proc on /proc type proc (rw,nosuid,nodev,noexec,relatime)
tmpfs on /dev/shm type tmpfs (rw,nosuid,nodev)
tmpfs on /run type tmpfs (rw,nosuid,nodev,mode=755)
tmpfs on /var/tmp/.font-unix type tmpfs (rw,relatime,exec)
```

**Задача.** Найти подозрительную точку монтирования и снять её атрибуты.

**Решение по шагам.**

**Шаг 1 — отделить штатные монтирования.** Виртуальные ФС: `proc` на `/proc`, `sysfs` на `/sys`, `tmpfs` на `/run`, `/run/lock`, `/dev/shm`. Дисковые разделы — `/dev/sdaN` на `/`, `/boot`. Всё это ожидаемо.

**Контрольный вопрос 1.1.** Какой тип ФС смонтирован на `/proc`? **Ответ:** `proc`

**Шаг 2 — найти выпадающую точку.** Есть `tmpfs`, смонтированный на `/var/tmp/.font-unix` (скрытое имя в `/var/tmp`) с опцией `exec`. Штатно `tmpfs` в таких местах не монтируют, а `exec` разрешает запускать оттуда файлы — это площадка для вредоносного кода.

**Контрольный вопрос 1.2.** На какую точку смонтирован подозрительный `tmpfs`? **Ответ:** `/var/tmp/.font-unix`

**Контрольный вопрос 1.3.** Какая опция монтирования делает её опасной? **Ответ:** `exec`

**Шаг 3 — оценить контекст.**

**Контрольный вопрос 1.4.** Сколько всего монтирований типа `tmpfs` в выгрузке? **Ответ:** `4`

**Вердикт.** Подозрительно: примонтирован исполняемый (`exec`) `tmpfs` в скрытом каталоге `/var/tmp/.font-unix` — площадка для запуска вредоносного кода. Зафиксировать точку и опции, эскалировать.

**Готовый результат.** В тикет: `tmpfs` на `/var/tmp/.font-unix`, опции `rw,relatime,exec`, нестандартное исполняемое монтирование, вердикт — подозрение на staging-площадку.

**Ключевые уроки.**
- FHS: `/etc`, `/var`, `/usr`, `/tmp`; виртуальные ФС — `proc` (`/proc`), `sysfs` (`/sys`), `tmpfs` (`/run`, `/dev/shm`).
- `tmpfs` живёт в памяти; стандартные точки — `/run`, `/run/lock`, `/dev/shm`.
- Опция `noexec` запрещает запуск файлов с раздела; общедоступные на запись каталоги обычно монтируют с `noexec`.
- `tmpfs` с `exec` в нестандартном (тем более скрытом) каталоге — площадка для запуска вредоносного кода.
