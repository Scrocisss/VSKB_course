**Покрывает листья** (ветка «Операционные системы / Основы Linux / Процессы и демоны»):
- Дерево процессов: PPID, PID 1 и systemd
- systemd: юниты, состояния и зависимости сервисов
- Типовые демоны и признаки аномалий для аналитика

**Сценарий.** Хостинг-провайдер «ОблакоСервис», 21 марта 2026, 10:35. Мониторинг показал 100% CPU на `web-prod-3`. Аналитик L1 снял список процессов (`ps -ef`).

**Исходные данные.** Файл `ps-ef-discovery.txt`. Штатные процессы и выпадающий:

```
UID          PID    PPID  C STIME TTY          TIME CMD
root           1       0  0 Apr19 ?        00:00:04 /sbin/init
root           2       0  0 Apr19 ?        00:00:00 [kthreadd]
root         712       1  0 Apr19 ?        00:00:00 /usr/sbin/sshd -D
deploy      3120     712  0 10:01 pts/0    00:00:00 -bash
deploy      4521    3120 98 10:32 pts/0    00:12:44 /tmp/.x/kdevtmpfsi
```

**Задача.** Найти аномальный процесс и снять его идентификаторы.

**Решение по шагам.**

**Шаг 1 — где запущены штатные демоны.** Системные процессы идут из `/sbin`, `/usr/sbin`, `/usr/lib`, `/usr/bin`; потоки ядра — в скобках. Процесс из `/tmp` или `/dev/shm` штатным не бывает.

**Контрольный вопрос 1.1.** Какой процесс является родителем всех демонов? **Ответ:** `init` (или `systemd`)

**Шаг 2 — найти выпадающий процесс.** Процесс `4521` запущен из `/tmp/.x/kdevtmpfsi` (скрытый каталог во временной папке) и грузит CPU на `98` (поле `C`) — типичный криптомайнер.

**Контрольный вопрос 1.2.** Какой PID у аномального процесса? **Ответ:** `4521`

**Контрольный вопрос 1.3.** Каков полный путь к его исполняемому файлу? **Ответ:** `/tmp/.x/kdevtmpfsi`

**Шаг 3 — снять контекст: пользователь и родитель.**

**Контрольный вопрос 1.4.** Под каким пользователем он запущен? **Ответ:** `deploy`

**Контрольный вопрос 1.5.** Какой PID у его родительского процесса? **Ответ:** `3120`

**Вердикт.** True Positive: майнер `/tmp/.x/kdevtmpfsi` (PID 4521, 98% CPU) запущен пользователем `deploy` из оболочки (PPID 3120). Снять PID, путь, родителя; эскалировать.

**Готовый результат.** В тикет: процесс PID 4521, `/tmp/.x/kdevtmpfsi`, UID `deploy`, PPID 3120, 98% CPU, вердикт TP — криптомайнер.

**Ключевые уроки.**
- `PID 1` (`init`/`systemd`) — родитель демонов; `PPID` показывает, кто породил процесс.
- Штатные демоны — из `/usr/sbin`, `/usr/lib`, `/usr/bin`; потоки ядра — в `[скобках]`.
- Процесс из `/tmp` или `/dev/shm`, высокий CPU у неизвестного процесса, `bash -i` — признаки аномалии.
- Снимать связку PID — путь — пользователь — PPID, она нужна L2 для расследования.
