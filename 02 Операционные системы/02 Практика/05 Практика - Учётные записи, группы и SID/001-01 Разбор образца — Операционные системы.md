**Покрывает листья** (ветка «Операционные системы / Основы Windows / Учётные записи, группы и SID»):
- Локальные и доменные учётные записи: отличия и видимость в логах
- Группы и встроенные роли Windows
- SID: структура и привязка к разрешениям

**Сценарий.** Торговая сеть «Берёзка-Ритейл», 20 марта 2026, 00:15. На кассовом ПК `KASSA-12` после серии алертов проверяют, не завёл ли атакующий собственного администратора. Аналитик L1 снял список учётных записей и членов группы `Administrators`.

**Исходные данные.** Файл `accounts-discovery.txt`:

```
C:\> wmic useraccount get Name,SID,Disabled,Lockout,PasswordRequired
Name                SID                                             Disabled  Lockout  PasswordRequired
Administrator       S-1-5-21-1187234044-2304199921-1456789012-500   TRUE      FALSE    TRUE
Guest               S-1-5-21-1187234044-2304199921-1456789012-501   TRUE      FALSE    FALSE
jsmith              S-1-5-21-1187234044-2304199921-1456789012-1001  FALSE     FALSE    TRUE
sysbackup           S-1-5-21-1187234044-2304199921-1456789012-1003  FALSE     FALSE    FALSE

C:\> net localgroup Administrators
Members
-------------------------------------------------------------------------------
Administrator
sysbackup
```

**Задача.** Найти учётную запись, добавленную в группу `Administrators` сверх ожидаемых, и снять её атрибуты.

**Решение по шагам.**

**Шаг 1 — прочитать членов группы `Administrators`.** Ожидаемые члены — встроенный `Administrator` и доменные/ИТ-администраторы. Всё остальное нужно объяснить.

**Контрольный вопрос 1.1.** Какой командой смотрят членов локальной группы администраторов? **Ответ:** `net localgroup Administrators`

**Шаг 2 — найти неожиданного члена.** В группе, кроме `Administrator`, состоит `sysbackup`. По таблице учёток это локальная запись (не доменная), имя маскируется под служебную «резервную копию».

**Контрольный вопрос 1.2.** Какая учётная запись лишняя в группе `Administrators`? **Ответ:** `sysbackup`

**Шаг 3 — прочитать SID и RID.** SID учётки `sysbackup` оканчивается на `-1003`. RID `1003` (≥ 1000) означает, что запись создана вручную, а не является встроенной (`500`/`501`).

**Контрольный вопрос 1.3.** Какой RID у `sysbackup`? **Ответ:** `1003`

**Шаг 4 — оценить риск.** У `sysbackup` `PasswordRequired = FALSE` — вход без пароля, и при этом она в `Administrators`. Это бэкдор-администратор.

**Контрольный вопрос 1.4.** Какое значение в колонке PasswordRequired у учётки `sysbackup`? **Ответ:** `FALSE`

**Контрольный вопрос 1.5.** Сколько всего членов в группе `Administrators`? **Ответ:** `2`

**Вердикт.** True Positive: создан локальный администратор `sysbackup` (RID 1003) без требования пароля — закрепление через учётную запись.

**Готовый результат.** В тикет: учётка `sysbackup`, SID `…-1003`, член `Administrators`, `PasswordRequired = FALSE`, вердикт TP — бэкдор-админ.

**Ключевые уроки.**
- SID = `S-1-5-21-<идентификатор машины или домена>-<RID>`; RID `500` — `Administrator`, `501` — `Guest`, `≥ 1000` — созданные вручную.
- Права даёт членство в группах: лишняя учётка в `Administrators`, особенно с RID `≥ 1000` и `PasswordRequired = FALSE`, — бэкдор-админ.
- Имена-маскировки (`sysbackup`, `support1`, `svc_*`) под службы и поддержку — частый приём.
- Встроенный `Administrator` (RID 500) на защищённых хостах обычно отключён (`Disabled = TRUE`); включённый — повод проверить.
