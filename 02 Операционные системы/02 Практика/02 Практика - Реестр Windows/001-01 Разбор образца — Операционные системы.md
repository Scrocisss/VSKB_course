**Покрывает листья** (ветка «Операционные системы / Основы Windows / Реестр Windows»):
- Кусты и разделы: HKLM, HKCU, HKCR, HKU
- Ключи автозапуска и персистентность
- Инструменты просмотра и резервное копирование кустов

**Сценарий.** Торговая сеть «Берёзка-Ритейл», 18 марта 2026, 09:30. SIEM поднял алерт «Запуск powershell со скрытым окном при входе пользователя» на кассовом ПК `KASSA-12`. Аналитик L1 запросил экспорт ключей автозапуска (`reg export "HKLM\…\Run"` и `reg export "HKCU\…\Run"`) и должен найти значение-источник.

**Исходные данные.** Файл `run-keys-discovery.reg`:

```
Windows Registry Editor Version 5.00

[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Run]
"IgfxTray"="C:\\Windows\\System32\\igfxtray.exe"
"RtkAudUService"="\"C:\\Windows\\System32\\RtkAudUService64.exe\" -background"
"SecurityHealth"="C:\\Windows\\System32\\SecurityHealthSystray.exe"
"VMwareUserProcess"="\"C:\\Program Files\\VMware\\VMware Tools\\vmtoolsd.exe\" -n vmusr"

[HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Run]
"com.squirrel.Teams.Teams"="C:\\Users\\jsmith\\AppData\\Local\\Microsoft\\Teams\\Update.exe --processStart Teams.exe"
"MicrosoftEdgeAutoLaunch_8F3"="\"C:\\Program Files (x86)\\Microsoft\\Edge\\Application\\msedge.exe\" --no-startup-window --win-session-start"
"OfficeUpdater"="powershell.exe -NoProfile -WindowStyle Hidden -EncodedCommand JABwACAAPQAgACcAaAB0AHQAcAA6AC8ALwAxADAALgAwAC4AMAAuADUAJwA="
"OneDrive"="\"C:\\Users\\jsmith\\AppData\\Local\\Microsoft\\OneDrive\\OneDrive.exe\" /background"
```

**Задача.** Найти значение автозапуска, запускающее подозрительный процесс, и снять его атрибуты.

**Решение по шагам.**

**Шаг 1 — где живёт автозапуск.** Значения в `[HKLM\…\Run]` стартуют для всех пользователей и требуют прав администратора на запись; в `[HKCU\…\Run]` — только для текущего пользователя и прав администратора не требуют. Атакующему без прав администратора проще закрепиться в `HKCU`.

**Контрольный вопрос 1.1.** В каком корневом кусте запись автозапуска не требует прав администратора? **Ответ:** `HKCU`

**Шаг 2 — пройти значения и найти выпадающее.** Легитимные значения запускают `.exe` из `System32`, `Program Files` или папок установленных программ (OneDrive, Teams, Edge — из `AppData`/`Program Files`). Значение `OfficeUpdater` запускает `powershell.exe` со скрытым окном и `-EncodedCommand` — нормальная программа автозапуска так не делает.

**Контрольный вопрос 1.2.** Какое значение автозапуска вредоносное? **Ответ:** `OfficeUpdater`

**Контрольный вопрос 1.3.** Какой процесс оно запускает? **Ответ:** `powershell.exe`

**Шаг 3 — в каком кусте сидит.** Значение `OfficeUpdater` находится в `[HKEY_CURRENT_USER\…\Run]` — закрепление на уровне пользователя, без прав администратора.

**Контрольный вопрос 1.4.** В каком корневом кусте прописано вредоносное значение? **Ответ:** `HKCU`

**Шаг 4 — оценить общий объём автозапуска.** Чтобы понимать поверхность, аналитик считает все значения в обоих ключах: 4 в HKLM + 4 в HKCU = 8.

**Контрольный вопрос 1.5.** Сколько всего значений автозапуска в выгрузке? **Ответ:** `8`

**Вердикт.** True Positive: закрепление через ключ автозапуска `HKCU\…\Run`, имя `OfficeUpdater` маскируется под обновление Office, запускает кодированный PowerShell.

**Готовый результат.** В тикет: значение `OfficeUpdater` в `HKCU\…\Run`, запускает `powershell.exe -EncodedCommand …`, вердикт TP — персистентность.

**Ключевые уроки.**
- `Run`-ключи `HKLM` и `HKCU` — классический автозапуск и место закрепления; проверять оба.
- Запись в `HKCU` не требует прав администратора — частый выбор атакующего без повышения привилегий.
- Значение автозапуска, запускающее `powershell.exe`/`rundll32.exe`/`cmd.exe` с аргументами (особенно `-EncodedCommand`) или бинарь из пользовательской папки, — сильный признак вредоносного.
- В реестре `.reg`-экспорт удваивает обратные слэши (`\\`) и экранирует кавычки (`\"`) — это формат файла, а не часть пути.
