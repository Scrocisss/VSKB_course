**Покрывает листья** (ветка «Сетевые технологии / Уровни TCP/IP / Межсетевой уровень»):
- IP: адресация IPv4 и IPv6, TTL и фрагментация
- Маршрутизация между сетями и таблицы маршрутов
- ICMP: диагностика и злоупотребления
- NAT и частные/публичные адреса: интерпретация в логах
- Пятикортеж в сетевом событии (src IP, dst IP, порт, протокол, направление)

**Сценарий.** Банк «ФинТраст», 22 марта 2026, 15:25. SIEM поднял алерт об исходящем соединении с сервера БД `db-core-1` на внешний адрес. Аналитик L1 снял таблицу соединений (`netstat -ant`).

**Исходные данные.** Файл `netstat-ant-discovery.txt`:

```
Proto Recv-Q Send-Q Local Address           Foreign Address         State
tcp        0      0 0.0.0.0:22              0.0.0.0:*               LISTEN
tcp        0      0 192.168.5.20:443           192.168.5.30:49887         ESTABLISHED
tcp        0      0 192.168.5.20:51234         185.220.101.47:4444     ESTABLISHED
```

**Задача.** Найти подозрительное соединение и снять его пятикортеж.

**Решение по шагам.**

**Шаг 1 — отделить внутренние соединения.** `Foreign Address` у внутренних соединений — частные адреса (`10.x`, `172.16–31.x`, `192.168.x`). Соединение с публичным адресом от внутреннего сервера нужно объяснить.

**Контрольный вопрос 1.1.** Какой IP-адрес назначения у подозрительного соединения? **Ответ:** `185.220.101.47`

**Шаг 2 — прочитать порт и протокол.** Соединение идёт на порт `4444` по `tcp` — нестандартный порт, не соответствующий веб-службе или БД. Это признак управляющего канала.

**Контрольный вопрос 1.2.** Порт назначения подозрительного соединения? **Ответ:** `4444`

**Контрольный вопрос 1.3.** В каком состоянии находится соединение? **Ответ:** `ESTABLISHED`

**Шаг 3 — снять источник (свою сторону пятикортежа).**

**Контрольный вопрос 1.4.** Локальный IP-адрес соединения? **Ответ:** `192.168.5.20`

**Контрольный вопрос 1.5.** Локальный порт соединения? **Ответ:** `51234`

**Вердикт.** True Positive: установленное соединение от внутреннего сервера `192.168.5.20` к публичному `185.220.101.47:4444` — вероятный C2-канал. Снять пятикортеж, эскалировать.

**Готовый результат.** В тикет: пятикортеж `192.168.5.20:51234 → 185.220.101.47:4444 tcp ESTABLISHED`, вердикт TP — подозрение на C2.

**Ключевые уроки.**
- Пятикортеж: IP и порт источника, IP и порт назначения, протокол — однозначно описывает соединение.
- Частные адреса (`10/8`, `172.16/12`, `192.168/16`) — внутри сети за NAT; публичные — снаружи.
- `ESTABLISHED` к публичному IP на нестандартном порту от внутреннего хоста — признак C2.
- Сервер, инициирующий исходящее соединение наружу, сам по себе подозрителен (серверы обычно принимают, а не инициируют).
