**Покрывает листья** (ветка «Обогащение алертов (Enrichment) / Каталоги внешних сервисов»):
- VirusTotal: первичная проверка файлов, IP, доменов и URL
- URLScan.io: анализ URL и веб-контента
- AbuseIPDB: репутация IP-адресов
- Shodan: открытые порты и сервисы по IP; интерпретация в триаже
- WHOIS и Passive DNS: история домена и резолвинга
- MISP: поиск IOC в базе инцидентов

**Сценарий.** Банк «ФинТраст», 27 марта 2026. В алерте набор индикаторов, по каждому нужно выбрать сервис обогащения.

**Исходные данные.** Индикаторы:
```
1) IP-адрес 185.220.101.47 — нужна репутация
2) Хэш файла D5B0A3F2... — нужны детекты антивирусов
3) URL http://secure-bank-verify.top/login — нужен анализ веб-контента
4) IP 185.220.101.47 — нужны открытые порты и сервисы
5) Домен secure-bank-verify.top — нужна история регистрации
```

**Задача.** Сопоставить каждый индикатор с подходящим сервисом.

**Решение по шагам.**

**Контрольный вопрос 1.1.** Каким сервисом проверить **репутацию IP**? **Ответ:** `AbuseIPDB`

**Контрольный вопрос 1.2.** Каким сервисом получить **детекты по хэшу файла**? **Ответ:** `VirusTotal`

**Контрольный вопрос 1.3.** Каким сервисом проанализировать **URL и веб-контент**? **Ответ:** `URLScan.io`

**Контрольный вопрос 1.4.** Каким сервисом узнать **открытые порты и сервисы по IP**? **Ответ:** `Shodan`

**Контрольный вопрос 1.5.** Каким сервисом узнать историю и регистрацию домена? **Ответ:** `WHOIS`

**Готовый результат.** Каждый индикатор обогащён своим сервисом: IP → AbuseIPDB/Shodan, хэш → VirusTotal, URL → URLScan, домен → WHOIS/Passive DNS; результаты — в тикет.

**Ключевые уроки.**
- IP → AbuseIPDB (репутация) и Shodan (порты/сервисы); файл/хэш → VirusTotal.
- URL → URLScan.io; домен → WHOIS / Passive DNS (история, регистрация).
- MISP — поиск индикатора в базе ранее зафиксированных инцидентов.
- Подбирать сервис под тип индикатора; результаты обогащения фиксировать в тикете.
