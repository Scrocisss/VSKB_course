**Покрывает листья** (ветка «Компьютерные атаки / MITRE ATT&CK»):
- Тактики MITRE — цели атакующего
- Техники и субтехники — конкретные методы
- Группы угроз и программы
- Применение ATT&CK: маппинг алертов на техники

**Сценарий.** Банк «ФинТраст», 25 марта 2026. Наблюдаемые действия в инциденте:
1. Открыто фишинговое вложение, получен первый доступ к хосту.
2. Макрос запустил PowerShell.
3. Создана задача cron для автозапуска.
4. Снят дамп `lsass` для извлечения учётных данных.
5. Хост поддерживает канал с внешним сервером управления.

**Задача.** Сопоставить каждое действие с тактикой ATT&CK.

**Решение по шагам.**

**Контрольный вопрос 1.1.** Тактика для получения доступа через фишинговое вложение? **Ответ:** `Initial Access` (Первоначальный доступ)

**Контрольный вопрос 1.2.** Тактика для запуска PowerShell? **Ответ:** `Execution` (Выполнение)

**Контрольный вопрос 1.3.** Тактика для cron-закрепления? **Ответ:** `Persistence` (Закрепление)

**Контрольный вопрос 1.4.** Тактика для дампа `lsass`? **Ответ:** `Credential Access` (Доступ к учётным данным)

**Контрольный вопрос 1.5.** Тактика для канала с внешним сервером управления? **Ответ:** `Command and Control`

**Готовый результат.** Цепочка тактик: Initial Access → Execution → Persistence → Credential Access → Command and Control. Маппинг помогает L2 быстро понять ход атаки.

**Ключевые уроки.**
- Тактика — цель атакующего (зачем), техника — конкретный метод (как).
- Типовая цепочка: Initial Access → Execution → Persistence → Privilege Escalation → Credential Access → Lateral Movement → Exfiltration/Impact.
- Маппинг алертов на ATT&CK даёт общий язык с L2 и помогает увидеть полную картину.
- Одно наблюдаемое действие = одна основная тактика (его цель).
