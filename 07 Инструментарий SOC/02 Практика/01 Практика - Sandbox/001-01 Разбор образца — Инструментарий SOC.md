- Статический vs динамический анализ

- Примеры: ANY.RUN, PT Sandbox, Kaspersky Sandbox

**Сценарий.** Банк «ФинТраст», 25 марта 2026, 08:30. Подозрительное вложение из письма отправлено в песочницу. Аналитик L1 получил отчёт.

**Исходные данные.** Файл `sandbox-discovery.txt` (фрагмент):

```
Verdict:       MALICIOUS
Threat Score:  92/100
Network IOCs:
  - DNS query: cdn-update-svc.net
  - C2: 185.220.101.47:4444 (TCP)
Dropped files:
  - C:\Users\Public\svc.exe  SHA256=D5B0A3F2C8E4179026B5C2DAF9E8071452B3C4D5E6F7A8B9C0D1E2F3A4B5C6D7
```

**Задача.** Снять из отчёта вердикт и индикаторы компрометации.

**Решение по шагам.**

**Шаг 1 — снять вердикт и оценку.** Песочница присвоила вердикт `MALICIOUS` с оценкой `92/100`.

**Контрольный вопрос 1.1.** Какой вердикт у образца? **Ответ:** `MALICIOUS`

**Контрольный вопрос 1.2.** Какая оценка угрозы? **Ответ:** `92`

**Шаг 2 — снять сетевые IOC.** В отчёте — C2-адрес и домен `cdn-update-svc.net`.

**Контрольный вопрос 1.3.** Какой адрес и порт сервера управления указаны в отчёте (через двоеточие)? **Ответ:** `185.220.101.47:4444`

**Контрольный вопрос 1.4.** Какой домен указан в сетевых IOC? **Ответ:** `cdn-update-svc.net`

**Шаг 3 — снять хэш сброшенного файла.**

**Контрольный вопрос 1.5.** Какой SHA256 у сброшенного файла? **Ответ:** `D5B0A3F2C8E4179026B5C2DAF9E8071452B3C4D5E6F7A8B9C0D1E2F3A4B5C6D7`

**Готовый результат.** В тикет/блок-лист: вердикт MALICIOUS (92), C2 `185.220.101.47:4444`, домен `cdn-update-svc.net`, хэш сброшенного `svc.exe` — для блокировки и обогащения.

**Ключевые уроки.**
- Песочница запускает файл в изоляции; статический (без запуска) + динамический (наблюдение поведения) анализ.
- Отчёт даёт вердикт, оценку угрозы, сетевые IOC (домены/C2), сброшенные файлы (хэши), дерево процессов, ATT&CK.
- Роль L1 — инициировать анализ и снять IOC из отчёта для блокировки и обогащения.
